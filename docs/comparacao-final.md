# Comparação final entre paradigmas

`[Preencher na etapa final]`

Este documento consolidará, ao fim do semestre, a comparação entre as quatro implementações do mesmo problema (imperativa, orientada a objetos, funcional e lógica), cobrindo pelo menos:

- representação de dados e de estado em cada paradigma;
- controle de fluxo;
- decomposição da solução;
- tratamento de efeitos colaterais;
- técnicas de abstração usadas;
- vantagens e limitações observadas na prática em cada paradigma para este problema específico.
